# Curso Nivel 1 de Telecomunicaciones

Repositorio oficial del curso virtual de Telecomunicaciones Nivel 1 para la Cruz Roja Colombiana Seccional Bolívar.

## Descripción
Este proyecto contiene el material didáctico interactivo, evaluaciones y recursos multimedia para la formación del personal voluntario y colaborador en el uso de equipos de telecomunicaciones en emergencias.

## Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript

## Estructura del curso
* Módulo 1: Introducción a las Telecomunicaciones
* Módulo 2: Equipos y Frecuencias
* Módulo 3: Procedimientos Operativos
* Módulo 4: Evaluación Final

## Créditos
Desarrollado para la Cruz Roja Colombiana Seccional Bolívar.
